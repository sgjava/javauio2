sudo nano /boot/armbianEnv.txt

Add spi-spidev to overlays=
Add param_spidev_spi_bus=1
Add param_spidev_spi_cs=0

Compile and apply the overlay:

sudo armbian-add-overlay duo-dual-spi.dts

Reboot the board:

sudo reboot

Check for active SPI devices and kernel output after boot:

ls -l /dev/spidev*
dmesg | grep -i spi
